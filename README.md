# AAU Debate · 辩论教练

一个辩论备赛 Skill：给出辩题和持方，产出可以直接上场的稿件。

方法论、写作规范、78 题特征库和真实环节稿范例，整理自**安徽农业大学校辩论队**的备赛数据。

## 功能

- **默认交付**：框架（定义与背景、判标、论点）、攻防（矩阵、接质口径、自由辩）、一辩稿、红队自检与核实清单。
- **只写一段**：指定环节、位置和字数，只交那一段。
- **只写一篇**：用户点名一辩稿之外的某一环节后，先问清这一环节的方向与核心诉求，再写那一篇；系统自定内容时，不复述一辩稿的论点句、案例、数据、类比。
- **整套备战包**：用户明确要“全套”时，才补齐首质、申论、驳论、盘问、小结、结辩。
- **只做局部**：只要框架、只要攻防，或在已有稿子上补全。

## 使用

直接用自然语言说清辩题、持方、环节和时长：

```text
帮我写一辩稿，题是“短视频让人更孤独还是更充实”，正方，3 分钟。
只写结辩，题是“时间能治愈一切”，反方，接下面这段盘问。
给我这套题的框架和攻防，不用写环节稿。
出整套备战包，赛制是校赛四人制。
```

默认只交框架、攻防、一辩稿和配套资料；点名其他环节稿才写那一篇；明确说“全套”“备赛包”，才补齐所有环节。

## 安装

把整个 `aau-debate/` 目录放进运行环境的 skills 目录，例如：

```text
.trae/skills/aau-debate/
```

## 校验

交付前跑一遍，整包（全环节）不加参数，默认交付、单篇或一段加 `--partial`：

```bash
python scripts/check_pack.py <备战包路径>
python scripts/check_pack.py <稿件路径> --partial
```

它查字数比例、禁用词、表格、交接话术、问句长度、块数与轮数、整句重复；“有没有接住上一环节”“像不像人话”这类判断仍需人工过。

## 数据来源与边界

- 方法论、讲座、真实稿片段和特征库，整理自安徽农业大学校辩论队的备赛资料。
- 特征库里的数字是旧题记录，不是事实来源，引用前需重新检索核实。
- 对外分发前，请自行确认内容中不含队内敏感信息与个人信息。
