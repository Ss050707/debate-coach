# debate-coach

一个辩论备赛 Skill：给出辩题和持方，产出可以直接上场的稿件。

方法论、写作规范、78 题特征库和真实环节稿范例，整理自**安徽农业大学校辩论队**的备赛数据。

## 功能

- **只写一段**：指定环节、位置和字数，只交那一段。
- **只写一篇**：一辩稿、申论、首质、盘问、盘问小结、结辩任选。
- **整套备战包**：框架、判标、论点、攻防、环节稿、红队自检、核实清单。
- **只做局部**：只要框架、只要攻防，或在已有稿子上补全。

## 使用

直接用自然语言说清辩题、持方、环节和时长：

```text
帮我写一辩稿，题是“短视频让人更孤独还是更充实”，正方，3 分钟。
只写结辩，题是“时间能治愈一切”，反方，接下面这段盘问。
给我这套题的框架和攻防，不用写环节稿。
出整套备战包，赛制是校赛四人制。
```

只说要一段，就不会补出整包；明确说“全套”“备赛包”，才走七章。

## 安装

把整个 `debate-coach/` 目录放进运行环境的 skills 目录，例如：

```text
.trae/skills/debate-coach/
```

## 目录结构

```text
debate-coach/
├── SKILL.md              入口：规则、工作流、校验清单
├── references/
│   ├── 00-索引/           总索引、检索、赛制、四本特征库、讲座、范例、人味规范
│   ├── 01-框架/           定义与背景、判标、论点与论证链
│   ├── 02-攻防/           攻防矩阵、接质口径、自由辩弹药
│   └── 03-环节稿/         一辩稿、首质、申论与驳论、盘问、小结、结辩
└── scripts/
    └── check_pack.py     交付前硬校验
```

## 校验

交付前跑一遍，整包不加参数，单篇或一段加 `--partial`：

```bash
python scripts/check_pack.py <稿件路径>
python scripts/check_pack.py <稿件路径> --partial
```

它查字数比例、禁用词、表格、交接话术、问句长度、块数与轮数、整句重复；“有没有接住上一环节”“像不像人话”这类判断仍需人工过。

## 数据来源与边界

- 方法论、讲座、真实稿片段和特征库，整理自安徽农业大学校辩论队的备赛资料。
- 特征库里的数字是旧题记录，不是事实来源，引用前需重新检索核实。
- 对外分发前，请自行确认内容中不含队内敏感信息与个人信息。
