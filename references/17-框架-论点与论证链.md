# 17 论点与论证链

> 所属：references｜分类：框架｜对应备赛包第三章｜示例题：把日常事务大量托管给智能体（正方）

## 先把论造出来

论点回答的是“我方为什么成立”。这一章只造论、不拆论：产出两个论点句、两棵论证树，外加每条论证链上的材料摆在哪儿。拆对方是攻防章的事，这里一字不写。

## 两个论点，两棵树

先定要几个论点、怎么分工。默认两个，每个都要能独立站住。论点句按“背景 → 反应 → 结论”写；单独把结论拎出来念一遍，也得站得住，站不住就是口号。

两个论点用四个视角错开：各用一句话概括，能互换就说明重叠，换视角重写。论证树一棵对一个论点，至少两层，叶子落到能查的数据、机理或案例——被打的时候才有地方退。

第二论点不知道往哪落，从这四个方向挑一个：弱者能不能因此获得行动能力；长期收益能不能抵住短期代价；制度成本是不是只有这条路能降；价值底线会不会被突破。挑一个，不要四个都沾。

每个论点内部按三层铺，别写成一段散文。第一层讲事实：现在是什么状况，用数据或案例把问题摆出来。第二层讲机制：因为什么，所以什么，写成“因为……所以……”能念顺的句子。第三层讲价值或门槛：这事对谁意味着什么，为什么非如此不可。每层先给一句推证逻辑，再上证据；证据是给逻辑作证的，不是反过来。案例要落到一个人身上：有名有姓，带一句原话或一个动作；数据尽量带样本量和机构，像“针对 2798 名青少年的调查”，比单给一个百分比可信。

每个论点结尾留一句结论口径，单独能念、能抄、能被记住。像“人不是因为拥有时间而自由，而是因为能够支配时间而自由”。这一句是评委唯一可能带走的东西，别让它淹没在数据里。

每条链上配齐数据、机理、案例三件套，逐条标【数据类】【机理类】【案例类】，后面跟机构、年份、口径、来源。链条最容易断在三个地方，每个断点提前备一句回应。

两个论点都要回扣同一把判准。收三句本场口径，全队照着说。

## 落笔时的几个习惯

论点句自带逻辑链，不靠形容词撑。论点句就是小标题，写成场上能直接念出来的整句，不要“关于效率的讨论”这种标签。论点里不出现“对方”“即便对方”“虽然有人会说”，零攻防、零让步；让一步，就等于把判准的边交出去。

每个论点 60–70 秒能讲完。讲不完先删例子，机理留着——例子是衣服，机理是骨头。论证树至少两层，叶子必须落在可查材料上，不然对方一戳就空。

没有来源的材料不写成事实。没检索到的写“待核实（缺：机构 + 年份 + 口径）”，不要拿大概的数字顶上去。不用表格，不靠形容词凑字数。

## 交稿前自己过一遍

- 是不是只有两个论点，而且不重叠？
- 每个论点句都走了“背景 → 反应 → 结论”吗？
- 每个论点都有两层以上论证树吗？叶子落到可查材料了吗？
- 每个论点有没有按“事实 → 机制 → 价值或门槛”三层铺？
- 每个论点结尾有没有一句能单独念的结论口径？
- 数据、机理、案例配齐了吗？类别和来源都标了吗？
- 三个断点各有一句回应吗？
- 每个论点 60–70 秒讲得完吗？
- 有没有“对方可能会说”“即便对方”？
- 两个论点都回扣同一把判准了吗？
