# 01 一辩稿

> 所属：03-环节稿｜对应 SOP 第 1 环｜范本：共情之殇、兰桨拨开雾霭迷茫、幸福祛魅三篇一辩稿｜默认 1300 字 / 210 秒
>
> 动笔前读 `references/00-索引/14-人味与去AI味.md`，把声音刻度和禁用词过一遍。

## 这一环节的声音：稳、慢，像把一把尺子放到桌上

评委听完这 210 秒，只该记住一件事：我方为什么成立。所以语速要稳，句子可以长一点，但不能空。

一辩稿是论的浓缩，不是资料堆，也不是百科朗读。开头二十秒定生死，但抓人靠的是判断和定义，不是硬塞一个故事。

## 开头直接进内容，不另造场景

三篇范本都是问候之后直接进定义或背景：共情稿从“何谓善良者”进，兰桨稿从年轻人的焦虑数据进，祛魅稿从“祛魅”一词的语境进。没有一篇先讲一个朋友的故事，也没有一篇靠一句反常识的话开场。照这个来：问候一句，下一句就进定义、背景或一个真问题；开头两句之内露出这道题的切口，但不铺百科，不写“随着经济社会的发展”。

## 三篇范本共同的结构

标准版是五块，整篇一般 6–8 段，不要一句一段：

1. 问候：一句，“各位好”或“谢谢主席，各位评委”。
2. 定义与判准：1–3 段。先把会争的关键词切开（“何谓 X？在我方看来……”），再交代背景或双方分歧；判准放在这一段末尾，写成“X 相比不 X，究竟……还是……”“这要看……”或“更有利于……”，不单独标“判准。”。
3. 论点一：1–2 段。先用一句完整判断领起，后面一大段把机理、数据、案例、回扣写完。
4. 论点二：1–2 段，同论点一，但换一个入口，不和论点一同构。
5. 收束：一句“所以，我方坚定认为……”或“以上。”，回扣判准。

三篇的差别只在论点句的位置：共情稿把论点句压在段首，兰桨稿和祛魅稿把论点句单独成段再展开。照内容挑，不固定。论点段一般 300–500 字，定义段 100–300 字；不要把论点拆成四五段。

## 三篇范本怎么排

**共情稿（1180 字，6 段）**：问候 → 定义“善良者”（引康德）→ 补一句“善良来自内化的道德准则”，段末落判准问题 → “第一，”一大段（巴以冲突的场景、无力感、共情耗竭、回扣）→ “第二，”一大段（水滴筹假病历、38 起热点事件一半反转、信任被惩罚、回扣）→ 收束一句。

**兰桨稿（1221 字，6 段）**：问候 + 焦虑数据 + 双方定义 + 立场 + “由此展开论证” → “物质层面上……”论点句单独成段 → 一大段（4700 万缺口、拖延数据、脉脉统计、北大保安、外卖骑手、回扣）→ “第二，心态层面上……”论点句单独成段 → 一大段（高善文数据、目标设定理论、回扣）→ “以上。”收束。

**祛魅稿（1339 字，7 段）**：问候 → 定义“赋魅/祛魅” + 段末落判准“这要看……” → “基于此，我方有如下论证”过渡 → 论点句单独成段 → 一大段（名校名师、大城市、产品、预期管理、回扣）→ 论点句单独成段 → 一大段（晕轮效应、爬泰山、爱情、回扣）→ 收束一句。

学结构，不抄句子。三篇里的“综上所述”在禁用词表里，成稿换成“所以，我方坚定认为……”或“以上。”；例子只学长度和展开方式，不搬原句。

短版三段，两分半以内、题面自带定义、或者价值题用：

1. 一句定调：不是 A，而是 B
2. 论点一、论点二，各自带机制和证据
3. 一句收束，回扣判准

短版可以不放定义和判准段，但判准必须藏在定调句里，评委会听出来你在比什么。别两版混着写，混着写就两头都不像。

## 一句一句写下去

定义可以照这个句式起手：“何谓 X？在我方看来……”，也可以从背景、数据或双方分歧进；不管从哪进，后面都要跟一句口语限定，把词典解释翻成人话：“我说的不是外卖里切好的净菜，是那袋撕开倒进锅里、热三分钟就能上桌的东西。”这一句决定评委觉得你在背定义，还是真的想过。

判准照这个起手：“在……上，X 相比不 X，究竟……”，也可以直接说“在……条件下，X 更有利于……”。判准不是口号，要能翻成“如果论证到 X，就说明我方证成”，而且这句话本身要说人话，不写“实现价值跃迁”这种词。判准压在两三句、六十字上下，别把备战包“判标”章那句带三个条件的长句原样搬进来——那是给队内看的，不是给评委听的。

定义或背景之后、论点之前，可以加一句过渡，不单独成段。像“合肥作为一座开放、创新的新一线城市，南北交融的地理特征决定了它的包容气质”，一句把话头接到论点。没有这句，定义直接跳到论点会显得硬。

本地题、校园题、行业题，用一个在地细节排比替掉空泛形容。地名、店名、人物名连着摆，画面自己会说话。像“包公园的梅花红墙，巢湖畔的晚风，逍遥津的银杏”，比十句“这座城市很有魅力”都管用。

## 论点段的声音：判断、展开、回扣

每个论点先给判断，展开时场景、数据、机理按内容排，不必每段都按同一个顺序。可以走“现象 → 机理 → 案例 → 回扣”，但别让两个论点长成同一个模子：一个可以从人进，一个可以从制度进；一个先给画面，一个先给数字。

每个论点只留一句能被评委带走的判断，放在段尾。别每段都造金句：金句一多，论证就断成口号，评委记住的是句子，不是你为什么对。

论据要对着机理挑，不是对着章节挑。讲“招聘半径”，就拿“远程岗位的申请者从多远来”的证据；拿残障、照护数据去讲招聘半径，评委听到的是“弱势群体需要照顾”，不是“半径扩大”。两条路只能走一条：要么换一组直接量招聘半径的证据，要么把论点改成“地点筛选把谁挡在门外”。相关但不直接的数据，宁可不写。

数据不限两组，限“有没有用”。每组数据都要回答上一句留下的问题：前一个数字留下问题，后一个数字回答它；两组数字只是并列，删一组。一个论点最多一个案例，案例要落在机理上。数字后面要跟一个人能看见的后果，不要排队：

> 调查里只有 18.2% 的大学生刷完短视频觉得愉悦，28% 的人说更空虚。

术语第一次出现，用大白话过一遍。比如“任务切换成本，就是刚从一件事里出来、又进另一件事时，脑子要重新热身”。这句话值三十秒，别省。

比较题的定义段，把双方关键词各切一句。态度题别只定义自己的词，把对方那个态度词也按你的理解钉住，否则场上会被他拖着定义跑。

## 这一篇的边界

零攻防、零预设，不写“对方可能会说”，不写“即便对方……我方也……”。允许一句边界与保障，比如“当然，这件事要可靠、要能分级、要能撤回”，只许一句，不算让步。

“第一、第二”只有这一篇能用。别写表格。

## 最容易写坏的四件事

**段段同构。** 两个论点都是同一个顺序，两段下来评委就听出模板了。改法：一段从人进，一段从制度进；一段先给数字，一段先给画面。

**判准写成公文。** 把备战包“判标”章那句带三个条件的长句原样搬进一辩稿，评委听完只记得一串名词。改法：压成两句、六十字上下，说清“比什么、怎么算赢”。

**数据排队。** 一口气报五个百分比，听众一个都记不住。改法：数字按链条排，前一个数字留下问题，后一个数字回答它；并列的删掉。

**论据不对机理。** 讲“招聘半径扩大”，却拿残障、照护数据来撑——评委听到的是“弱势群体需要照顾”，不是“半径扩大”。改法：要么换一组直接量招聘半径的证据，要么把论点改成“地点筛选把谁挡在门外”，两条路只走一条。

## 交稿前，自己过一遍

- 五块齐不齐，顺序有没有乱；整篇是不是 6–8 段，有没有一句一段或一大段不分块；用了短版三段，判准有没有藏在定调句里
- 开头是不是问候后直接进定义、背景或真问题，有没有硬塞场景、反常识句或铺百科
- 开头两句之内有没有露出那道题的切口，露了几次
- 有没有预设攻防、“对方可能会说”；边界与保障句是不是只有一句
- 定义是不是只切了 1–2 个争议词，后面有没有一句口语限定
- 判准有没有放在定义或背景段末尾，不单独标“判准。”；能不能写成“如果论证到 X，就说明我方证成”，说的是不是人话
- 两个论点是不是长成了两个模子，有没有同构
- 每个论点是不是把判断、展开、回扣走完了，有没有只剩例子或只剩数据
- 每组数据是不是都在推进同一条链，有没有两组只是并列的数字；案例是不是落在机理上
- 论据是不是直接回答论点，有没有拿相关但不直接的数据凑
- 判准是不是两句以内、说人话，有没有直接搬判标章的长句
- 有没有每段都造金句，金句是不是盖过了论证
- 有没有一个只有这道题才有的细节：时间、地点、动作、原话
- 是不是只有这一篇用了“第一、第二”
- 字数是不是落在目标 92%–108%
- 结尾是不是回扣判准，而不是喊口号
- 出声读一遍，有没有卡嘴
- 有没有表格
